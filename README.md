# 精神病院的農舍照護（1899） / The Care of the Insane in Farm Dwellings — Transcription Dataset

G. Alder Blumer 於 1899 年記錄紐約州 Utica 精神病院將部分住院者安排於農舍的實際經驗，包括居住分配、日常工作、管理人員、費用，以及需要轉回主院的情形。

G. Alder Blumer’s 1899 article describes farm dwellings used by Utica State Hospital. The report discusses patient selection, accommodation, day-to-day occupation, supervision, costs, and return to the main institution.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
